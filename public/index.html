ABOUT THIS BUILD

A prototype for engineering memory.

This interface demonstrates the product flow from the hackathon brief: ask a natural-language “why” question, inspect a decision graph, follow evidence to source records, see earlier decisions marked as superseded, and refuse to answer when the graph lacks enough support.

Live todayPublic GitHub ingestion, heuristic decision candidates, graph links, keyword-based evidence retrieval, source inspection.
Next integrationNeo4j AuraDB for persistent graph storage, an LLM extractor, and GraphRAG for richer retrieval and grounded response generation.
